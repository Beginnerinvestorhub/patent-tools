# Informal vs. Formal Drawings

## Important terminology note (current as of this writing)

Per MPEP § 608.02(b): **the USPTO no longer formally classifies drawings as
"formal" or "informal."** Drawings submitted with an application are now
simply **acceptable** or **unacceptable** — accepted by the Office of Patent
Application Processing (OPAP) if they are readable and reproducible for
publication purposes (see MPEP § 507). If an examiner finds the drawings
lacking, prosecution can often continue anyway, with the drawings "admitted
for examination purposes only" and an objection that must be corrected
before allowance.

That said, "informal" and "formal" remain very common working shorthand
among patent practitioners, applicants, and pro bono programs, so expect
users and their advisors to use these terms. Use them when
communicating with humans, but don't rely on outdated MPEP language when
double-checking a specific procedural point — verify against current MPEP
§ 608.02(b) and § 507 language, since terminology and specific procedures do
get updated.

## Informal drawings (colloquial — "not yet 37 CFR 1.84 compliant")

- Purpose: secure a filing date and let examination begin.
- Must still be clear enough for an examiner to understand the invention —
  but do not need to hit every 37 CFR 1.84 formatting rule perfectly.
- Good strategy when: cost or time pressure means formal drawings aren't
  ready yet, or the applicant is still refining the invention description
  and doesn't want to pay for formal figures that might need to change.
- Risk: USPTO will issue a Notice to File Corrected Application Papers (or
  similar) requiring formal drawings, typically with about a 2-month window
  to respond. Missing that window risks abandonment — treat the deadline as
  firm.

## Formal drawings (colloquial — "fully 37 CFR 1.84 compliant")

Source: MPEP § 608.02(a)–(b).

- Must pass every rule in
  [uspto-37cfr184.md](uspto-37cfr184.md) /
  [compliance-checklist.md](compliance-checklist.md).
- Required before a patent can be allowed/issued.
- This is where most professional patent illustrator cost is spent — but if
  the applicant (or someone on their team) has drafting skill and can hit
  the formatting rules precisely, formal drawings can be self-prepared,
  which this skill is built to support.

## Sequencing recommendation

1. File with clean informal drawings to lock in the filing date.
2. Use the extra time to refine figures toward full formal compliance —
   running them through this skill's checklist iteratively.
3. Submit formal drawings before the Notice deadline, or as part of the
   original filing if they're already compliant — either is fine, but don't
   let the 2-month clock run out once a Notice is issued.
