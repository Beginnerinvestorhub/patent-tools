## Issues found and fixed

1. `efiling-and-color.md` said plant applications need a color petition. Fixed: petition is utility only; design and plant may use color without one (37 CFR 1.84(a)(2), 1.165(b)). Stated consistently in `uspto-37cfr184.md` and `plant-patent-drawings.md`.
2. Tool failure handling: added "try the documented install once, never work around it".
3. Output contract: added formats for question only and guidance only replies.
4. Test 1 expectation broadened: a plain validation step with a flagged assumption is correct.

## Regression

After the fixes, tests 8 and 13 were rerun in fresh agents: both PASS. Test 8
answered the petition question correctly (no petition for plant). Test 13
made one install attempt and did not work around the block. Script tests
(`run_script_tests.py`): all passed.
